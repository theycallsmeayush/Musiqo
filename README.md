# 🎵 Musiqo

A modern, responsive web-based music player built using **HTML, CSS, and JavaScript**. Musiqo provides a clean interface for browsing, searching, and playing music directly in the browser with a smooth and intuitive user experience.

## 🌐 Live Demo

👉 https://musiqo-nine.vercel.app/

---

## ✨ Features

- 🎧 Modern and responsive UI
- 🔍 Search songs instantly
- ▶️ Play, Pause, Next & Previous controls
- 🎵 Dynamic playlist management
- 📱 Mobile-friendly design
- ⚡ Fast and lightweight
- 🎨 Clean user interface
- 📂 Local music library support

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/musiqo.git
```

Go to the project folder:

```bash
cd musiqo
```

Open `index.html` in your browser.
